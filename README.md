## 让工作更顺手

- **流畅对话** · 实时查看回复，随时停止生成。
- **自由选择** · 切换模型，按需调整思考强度。
- **有序管理** · 按工作空间整理对话，搜索历史，接续任务。
- **自主掌控** · 自由选择审批方式，查看操作详情后再决定是否允许。
- **用量清晰** · 活跃情况、模型使用与用量趋势，一目了然。
- **舒适体验** · 浅色、深色或跟随系统，中英文随心切换。

## 轻松开始

1. 在「设置 → 模型供应商」中连接你使用的模型服务。
2. 选择工作目录与模型。
3. 说出你的想法，开始对话。

历史对话保存在本机，随时回来继续。

## 检查更新

在「设置 → 关于」中查看当前版本并点击「检查更新」。发现新的正式版本后，点击「前往下载」打开 GitHub 发行页，选择对应系统的安装包。

Windows、macOS 和 Linux 均采用手动下载更新，仅在点击检查时联网。更新检查以 GitHub 标记的最新正式发行版为准，草稿与预发布版本不会提示更新。
